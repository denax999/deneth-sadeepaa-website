# Deneth Sadeepa — Personal Website

Official personal website for **Deneth Sadeepa**, known online as **Denax**.

The site is designed as a personal profile/creator website and includes structured data for a `ProfilePage` + `Person` entity, canonical metadata, social profile connections, a sitemap and robots.txt.

## Files
- `index.html` — main website, SEO metadata and JSON-LD structured data
- `style.css` — design, responsive layout and animations
- `script.js` — scroll animations, mobile menu and cursor glow
- `assets/profile.jpg` — official profile image
- `robots.txt` — crawler instructions and sitemap location
- `sitemap.xml` — canonical site URL

## Publish on GitHub Pages

1. Upload all files and folders to the GitHub repository used for the site.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your main branch and the `/ (root)` folder.
5. Open the published URL and test the navigation and social links.

## After publishing: Google setup

1. Add the published site to **Google Search Console**.
2. Verify ownership.
3. Use URL Inspection for the canonical homepage URL:
   `https://denax999.github.io/deneth-sadeepaa-website/`
4. Submit:
   `https://denax999.github.io/deneth-sadeepaa-website/sitemap.xml`
5. Keep the same public name (`Deneth Sadeepa`) and online name (`Denax`) consistently across official profiles.

A Knowledge Panel cannot be guaranteed by website code alone. Google determines Knowledge Panel eligibility and data from signals across the public web.
