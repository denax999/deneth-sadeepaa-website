# Deneth Sadeepa — Personal Website

A simple, animated, black-and-white personal portfolio for **Deneth Sadeepa (Denax)**.

## Files
- `index.html` — main website
- `style.css` — design, responsive layout and animations
- `script.js` — scroll animations, mobile menu and cursor glow
- `assets/profile.png` — profile image

## Publish on GitHub Pages (free)

1. Create a GitHub account at https://github.com/ if you do not have one.
2. Click **New repository**.
3. Name it something like `deneth-sadeepa-website`.
4. Keep it **Public** and create the repository.
5. Upload **all files and folders from this project**.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select your main branch (usually `main`) and the `/ (root)` folder.
9. Save. GitHub will give you your public website link.

## Editing the site

The easiest place to change your details is `index.html`.
Search for:
- `Deneth Sadeepa`
- the About text
